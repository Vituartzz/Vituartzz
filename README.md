## About me

Full-stack developer focused on **TypeScript, React/Next.js and Node.js**. I design, build and run
systems that real businesses depend on every day — point of sale, payments, e-commerce sync,
financial reports and WhatsApp/e-mail automation — from the database schema to the deploy.

- 🏗️ **End-to-end ownership:** data modeling, APIs, UI, integrations, monitoring and production migrations
- 💳 **Money-safe code:** integer-cent arithmetic, idempotent webhooks, row locks on concurrent writes
- 🔐 **Security by default:** JWT + 2FA, role-based access, multi-tenant data isolation, LGPD-aware audit logs
- ✅ **Tested where it matters:** pure business rules covered by Jest; E2E with Playwright
- 📚 Currently studying **System Design**, **Clean Architecture** and **DevOps**

## Production work

> Private repositories built for clients — code can't be shared, but I'm happy to walk through the architecture in an interview.

#### 💎 Retail ERP & POS — jewelry store chain
Multi-store management system running in production every day at the counter.

- **POS** with Mercado Pago Point terminals and Pix (server-side price validation, refunds, cash-register reconciliation)
- **E-commerce sync** with Nuvemshop: stock, prices, photos, orders and in-store pickup with verification codes
- **Commission, payroll and financial engine** in integer cents, with monthly goals and automated alerts
- **WhatsApp Business (Meta templates) + e-mail** notifications: receipts, payment links, task alerts
- Ticket queue with TV display and text-to-speech, Kanban with real-time chat, customer map with geocoding
- Scheduled jobs and webhooks with idempotency, Discord alerting and structured logging

`Next.js 16` · `React 19` · `TypeScript` · `Prisma` · `PostgreSQL (Neon)` · `Mercado Pago` · `Nuvemshop API` · `Vercel` · `Jest` · `Playwright`

#### 💬 MyAgentez — WhatsApp messaging platform
Messaging service on the official WhatsApp Business API that other systems call to send messages and run automations,
including a text assistant that turns WhatsApp requests into Kanban tasks.

`Next.js` · `TypeScript` · `Prisma` · `WhatsApp Business API`
